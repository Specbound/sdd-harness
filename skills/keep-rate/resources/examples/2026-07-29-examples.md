## Worked Example: Distinguishing Window Artifacts from Code Quality Decline
**Scenario:** Keep Rate computed 92% on 2026-07-26 (14 commits aged 7-30d). On 2026-07-29, recompute shows 79.1%. Appears to be regression. Investigation reveals two low-survival infra commits (DuckDB dep 0/14, table_query 58/1523=3%) just aged past 30d cutoff on 2026-07-27, removing them from denominator naturally.

**Correct application:** Before flagging regression, check commit dates. Recompute keep-rate excluding known-low-survival categories (infra, dep-sweep, reverts). If feature-code subset shows 90%+, label as window artifact, not drain.

**Common mistake:** See 13pp drop and flag code quality regression immediately. Miss the window effect where deletion of old low-survival commits improves aggregate without any new work.
