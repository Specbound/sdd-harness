# Session Examples — 2026-10-07

## Already-Tracked Files in .gitignore

**Mistake:** Adding `.claude/` to `.gitignore` and expecting `git status` to stop showing it (committed in fc483eb).

**Fix:** Run `git ls-files .claude/` first. If tracked, use `git rm --cached -r .claude/` before editing `.gitignore`. `.gitignore` only prevents *future* tracking.
