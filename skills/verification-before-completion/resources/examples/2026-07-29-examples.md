## Worked Example: Verifying Code Removal Completeness
**Scenario:** Removing ShortTermMemoryAgent module from codebase. Primary commit deletes main module files successfully; CI passes locally but fails on merge due to orphaned test-mock references in test suite.

**Correct application:** Before committing deletion, run `grep -r "ShortTermMemoryAgent" . --include="*.py"` across full repo. Check tests/, configs/, env-setup, mock files. Document removal of each reference.

**Common mistake:** Delete the primary module directory, assume all references are gone, commit without full-repo verification. Test-file imports and config references remain hidden until CI runs.
