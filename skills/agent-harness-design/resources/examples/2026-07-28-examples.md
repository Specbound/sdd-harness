## Worked Example: Dual-Copy File Desync Caught Too Late

**Scenario:** A commit updates `scripts/setup/headroom-setup.sh` but the mirror `.claude/scripts/setup/headroom-setup.sh` stays stale. The inconsistency isn't caught until the next day when someone runs the mirror version and hits unexpected behavior.

**Correct application:** Before committing, governance should enforce: any tracked source/mirror file pair must be kept in sync via automated pre-commit check (diff both, block if diverged).

**Common mistake:** Trusting edits to stay in-sync across both copies without automated enforcement; relying on manual discipline recreates the same debt on every edit cycle.
